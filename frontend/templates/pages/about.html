{% if lang == 'zh' %}项目简介{% else %}Introduction{% endif %}

{% if lang == 'zh' %} 给定一份研究简报（方向 / 约束 / 排除项 / 知识文件），HAA 自动走完三阶段： P1 批量产出论文前体（想点子、联网查重、构造反例筛查、断网设计证明、定级、实验设计、写论文前半部、四路盲审批稿、精修）， P2 用 Claude Code（via ACP）生成实验代码，DebugSession 双阶段断路器调试执行并分析结果， P3 整合理论 + 实验为完整论文（Markdown→LaTeX→pdflatex→.zip 打包交付）。 人工只在 ARV / EA / 最终交付三个关卡做决策；Agent 最高只能把项目设为「濒死」，废止权始终在用户手中。 {% else %} Given a research brief (direction / constraints / exclusions / knowledge files), HAA runs three phases automatically: P1 produces paper precursors in batch (idea seeking, web dedup, adversarial screening, offline proof design, grading, experiment design, front-half paper writing, four-lens blind review, refinement); P2 generates experiment code via Claude Code (through ACP), debugs/executes it with a dual-phase circuit breaker, and analyzes results; P3 integrates theory + experiments into a full paper (Markdown → LaTeX → pdflatex → packaged .zip deliverable). Humans only decide at the ARV / EA / final-delivery gates; the agent's highest authority is MORIBUND — only the user can ABORT. {% endif %}

{% if lang == 'zh' %}三阶段流程{% else %}Three-phase pipeline{% endif %}

PR (人工简报: 死格式md直读 / 自由格式编译 / YAML)
 → P1 批量前体（SEEK→NOVELTY→SCREEN→DESIGN⇄VERIFY→GRADE→EXP_SPEC→HUMAN_REVIEW→WRITE→REVIEW⇄REFINE→PUBLISHED）
   简报铁律块注入十阶段 · fidelity lens 审简报委托 · 论文前半部四节
 → ARV 人工遴选（多选 + 下载 .md）→ P2（CODE_GEN→EXECUTE DebugSession→ANALYZE）
 → EA 人工评析 → P3（PAPER_INTEGRATE→MD2LATEX→LATEX_COMPILE→PACKAGE）
 → DONE → 人工批准 → COMPLETED

{% if lang == 'zh' %}核心设计原则{% else %}Core design principles{% endif %}

  • {% if lang == 'zh' %}代码状态机{% else %}Code-driven state machine{% endif %} — {% if lang == 'zh' %}模型不知道自己在哪步，代码决定下一步{% else %}the model never knows which stage it is in; the code decides{% endif %}
  • {% if lang == 'zh' %}双层预算先预留{% else %}Dual-layer pre-reserved budget{% endif %} — {% if lang == 'zh' %}先扣再发请求，收割环节不被预算卡掉{% else %}pre-deduct before each call; harvesting stages are never budget-gated{% endif %}
  • {% if lang == 'zh' %}自建工具 + 安全沙箱{% else %}Owned tools + safe sandbox{% endif %} — {% if lang == 'zh' %}路径白名单 / 命令黑名单 / 进程组钳杀 / 流式双闸（空闲 300s·墙钟 1800s）{% else %}path allowlist / command blocklist / process-group kill / streaming dual gate{% endif %}
  • {% if lang == 'zh' %}物理致盲四路审稿{% else %}Physically blinded four-lens review{% endif %} — {% if lang == 'zh' %}correctness / quality / industry / fidelity（简报符合性）独立打分{% else %}correctness / quality / industry / fidelity score independently{% endif %}
  • {% if lang == 'zh' %}简报铁律全程注入{% else %}Brief ironclad injection{% endif %} — {% if lang == 'zh' %}约束逐字送达十个阶段，偏离即被 fidelity 审击落{% else %}verbatim constraints reach every stage; drift is shot down by the fidelity lens{% endif %}
  • {% if lang == 'zh' %}主张成对{% else %}Paired claims{% endif %} — {% if lang == 'zh' %}每个结论配一个反方向，随候选流转{% else %}every claim carries a counter-direction through the candidate queue{% endif %}
  • {% if lang == 'zh' %}结构化可观测 + 断点恢复{% else %}Structured observability + crash recovery{% endif %} — {% if lang == 'zh' %}events 表记录每一分钱与每次截断；checkpoint 原子写 + resume-p1 续跑 + 启动配置 banner{% else %}events table records every cent and truncation; atomic checkpoints + resume-p1 + config banner{% endif %}
